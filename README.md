# Dashboard de Vendas com Python, Pandas e Plotly

Este projeto tem como objetivo apresentar um **dashboard interativo** para análise de dados de vendas. Ele foi desenvolvido como parte da minha formação em Análise de Dados.

## 📊 Funcionalidades

- Visualização de métricas de vendas (totais, por produto, por data etc.)
- Filtros interativos para facilitar a análise
- Gráficos dinâmicos com Plotly e Dash

## 🛠️ Tecnologias Utilizadas

- Python
- Pandas
- Plotly
- Dash
- Jupyter Notebook

## ▶️ Como executar

1. Clone este repositório:
 
 git clone https://github.com/Anac95/App-Dash.py.git


2. Instale as dependências:
pip install -r requirements.txt

3. Rode o app (se aplicável):
python nome_do_arquivo.py
Ou, se estiver em um notebook Jupyter, abra o .ipynb e execute célula por célula.
